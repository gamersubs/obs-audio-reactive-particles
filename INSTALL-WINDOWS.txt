Audio Reactive Particles - OBS Studio 33.0.1 (Windows x64)

This ZIP uses the OBS Studio 33+ third-party plugin layout.

1. Close OBS Studio completely.
2. Extract the ZIP.
3. Copy the extracted folder named "obs-audio-reactive-particles" into:

   C:\ProgramData\obs-studio\plugins\

The final paths should be:

   C:\ProgramData\obs-studio\plugins\obs-audio-reactive-particles\obs-audio-reactive-particles.dll
   C:\ProgramData\obs-studio\plugins\obs-audio-reactive-particles\data\particle.png
   C:\ProgramData\obs-studio\plugins\obs-audio-reactive-particles\data\locale\en-US.ini

Do not place this OBS 33 package in Program Files\obs-studio\obs-plugins.
That is the legacy plugin location.

If an older copy of this plugin is already installed in the legacy Program Files
location, remove that old copy after confirming that the ProgramData copy loads.

Start OBS and add the source using Sources > + > Audio Reactive Particles.
